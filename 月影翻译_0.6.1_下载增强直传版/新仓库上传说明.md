# 月影翻译：新 GitHub 仓库上传说明

这是“仓库根目录直传版”。**不要再创建 `MoonShadowTranslate_0.x.x` 子目录。**

## 正确的仓库结构

```text
仓库根目录
├── .github/
│   └── workflows/
│       └── build-android-apk.yml
├── android_patch/
├── assets/
├── lib/
├── tooling/
├── pubspec.yaml
├── README.md
├── ANDROID_SETUP.md
├── APK构建说明.md
└── 月影翻译使用说明.md
```

## 上传方法

1. 解压本压缩包。
2. 打开新建的 GitHub 仓库，保持在 `main` 分支。
3. 选择 **Add file / 添加文件 → Upload files / 上传文件**。
4. 上传**解压后的全部内容**，而不是再上传外层文件夹。
5. 提交。
6. 打开 **Actions / 操作 → Build 月影翻译 Android APK**。
7. 点 **Run workflow / 运行工作流程**。
8. 成功后在运行详情页底部 **Artifacts / 附件** 下载 APK。

## 以后升级版本

以后不再新建版本目录。直接在仓库根目录覆盖新文件，并修改 `pubspec.yaml` 中：

```yaml
version: 0.6.1+11
```

工作流会自动读取版本号并给 APK 命名。

## 当前本地翻译方案

当前版本使用 Qwen3 GGUF + llama.cpp 的本地 AI 翻译路线，不依赖 ML Kit Translation，也不需要 API Key。ML Kit 仅继续用于 OCR 文字识别。
