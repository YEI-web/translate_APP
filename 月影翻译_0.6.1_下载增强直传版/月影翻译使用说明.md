# 月影翻译 v0.6.1 中文使用说明

## 1. 第一次安装

安装 `月影翻译-Android-v0.6.1-arm64.apk` 后打开 App。

如果只想免费、不配置任何 API Key：

1. 点右上角 **设置**。
2. 找到 **本地 AI 翻译模型（无需 API Key）**。
3. 点 **下载**。
4. 等模型下载完成（约 429 MB）。
5. 回到主页，翻译引擎选择 **本地 AI（无需 Key）**。

以后模型保存在手机里，可以断网翻译。

## 2. 普通翻译

- 选择源语言，或者保留“自动检测”。
- 选择目标语言。
- 输入文字。
- 风格选“自然 / 正式 / 学术”。
- 点击 **翻译**。

本地 AI 会自行判断“自动检测”的语言，不再调用 ML Kit Translation 或 Language ID。

## 3. 本地 AI 模型

当前模型：`Qwen3-0.6B-Q4_0.gguf`。

特点：

- 无 API Key
- 模型下载后无需网络
- 文本不需要发送到翻译服务器
- 一个模型支持多语言，不用每个语言对单独下载模型

代价：

- 模型约 429 MB
- 运行时比传统机器翻译更占内存
- 老手机翻译速度可能较慢

如果不再需要，可在设置中点击 **删除** 释放空间。

## 4. 截图翻译

Android 屏幕翻译流程：

`屏幕捕获 → 本地 OCR → 当前翻译引擎`

如果当前引擎是“本地 AI”，并且“云端 OCR 回退”关闭，那么截图文字识别与翻译都可以在本机完成。

注意：OCR 仍使用 ML Kit Text Recognition；v0.6.1 移除的是 **ML Kit Translation**，不是 OCR。

## 5. 分享 / 长按文字

支持 Android 标准的：

- 分享文字到“月影翻译”
- 长按文字 → 处理文字 → 月影翻译

收到文本后会进入 App 并使用当前选中的翻译引擎。

## 6. 语音与朗读

- 麦克风按钮：使用 Android 系统语音识别获取一句话，再翻译。
- 朗读：使用 Android 系统 TTS 朗读译文。

## 7. 在线引擎

DeepL、Microsoft、Google Cloud、AI/OpenAI-compatible 都保留，需要相应 Key。你完全可以不配置它们，只使用本地 AI。

## 8. 常见问题

### 提示“本地 AI 模型尚未下载”
进入设置下载模型。

### 下载很慢或失败
模型约 429 MB，需要稳定网络。当前版本还没有断点续传，失败后重新点下载即可。

### 翻译很慢
这是本机运行神经网络的正常现象。较短句子会明显快于长文。当前版本优先稳定性，默认 CPU 推理；后续会再测试 GPU 加速。

### 手机上安装不了
当前测试 APK 重点针对 Android 8+ 的 ARM64 手机。

### ML Kit 还在项目里吗？
只保留 **OCR Text Recognition**。翻译链路已经换成 Qwen3 + llama.cpp。


## 模型下载失败怎么办（v0.6.1）

如果设置页下载 Qwen 模型失败：

1. 先再次点击“下载”，程序会保留 `.part` 文件并尝试断点续传。
2. 程序会自动尝试 Hugging Face 与备用镜像。
3. 如果仍无法下载，可在浏览器或电脑下载 `Qwen3-0.6B-Q4_0.gguf`。
4. 把模型文件传到手机。
5. 打开“设置 → 本地 AI 翻译模型 → 导入本地 GGUF”，选择该文件。
6. 导入成功后即可离线翻译。
